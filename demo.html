About

Why our heroes are GIFs

Motion grabs attention in the first second — before a single word is read. A looping GIF autoplays everywhere from one <img> tag: no video codecs, no muted-autoplay policies, no player chrome, no JavaScript. And because every loop we ship is mathematically exact, there is never a hard cut — the motion reads as ambient atmosphere, not a repeating clip. The same file drops unchanged into a GitHub README, an email, Notion or a slide deck.

20,000dots per frame, one function
80frames per seamless loop
0dependencies, textures or meshes
~40lines of JavaScript per beast
